# Eliá SPA Altiplano — site front-end

Site estático (HTML, CSS e JavaScript puros). Não precisa de instalação.

## Como abrir
Dê dois cliques em `index.html` ou publique a pasta inteira em qualquer hospedagem estática (Netlify, Vercel, GitHub Pages, Hostinger etc.).
A fonte (Google Fonts) e o mapa precisam de internet.

## Estrutura
- `index.html`: conteúdo e textos
- `css/style.css`: cores e tipografia no topo (`:root`)
- `js/main.js`: vídeo de fundo, cabeçalho e visualizador de fotos
- `assets/video/`: vídeo em loop (14 s, sem áudio) e imagem de capa
- `assets/img/`: fotos do espaço

## O que ajustar antes de publicar
- Confirme a lista de serviços, os horários e os textos em `index.html`.
- Adicione o link do Instagram no rodapé, se quiser.
- Algumas fotos foram enviadas por clientes no Google. Peça autorização (ou troque por fotos do próprio spa) antes de publicar.
- Substitua o vídeo trocando `assets/video/elia-loop.mp4` (formato MP4/H.264, sem áudio, de preferência com menos de 5 MB).
